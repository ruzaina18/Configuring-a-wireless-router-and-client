# Home Network Configuration and Security Lab

## Overview
Completed a simulated home network configuration using Cisco Packet Tracer. The lab involved connecting network devices, configuring a wireless router, setting up DHCP, securing a wireless network, and verifying connectivity between clients and the internet.

## Objectives
- Connect a cable modem, wireless router, PCs, laptop, and TV.
- Configure DHCP for automatic IP address assignment.
- Configure the wireless network SSID.
- Enable WPA2 Personal wireless security.
- Change the default router administrator password.
- Verify connectivity between clients and the simulated internet.

## Tools Used
- Cisco Packet Tracer
- Wireless router and simulated network clients
- DHCP, IPv4, and WPA2 Personal

## Implementation
1. Connected the cable modem to the wireless router.
2. Connected desktop computers using Ethernet cables.
3. Configured DHCP and checked client IP addressing.
4. Changed the router's administrator password.
5. Configured the wireless SSID and WPA2 passphrase.
6. Connected the laptop to Wi-Fi.
7. Tested connectivity from the laptop and desktop computers.

## Security Recommendations
- Use a unique, strong administrator password.
- Use WPA3 where supported, or WPA2-AES on compatible devices.
- Keep router firmware updated.
- Disable WPS if it is not required.
- Review connected devices and disable unnecessary remote administration.

## Results
The lab was completed in Cisco Packet Tracer. The configured clients were tested for connectivity to the simulated internet.
